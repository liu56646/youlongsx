#       的锚点还在、哪些失效，从而知道要重表达哪些。
#
# 格式（`|` 分隔，字段两侧空格随意）：
#     name | root | relpath | token | [mark]
#   root    : qemu = $SRC_DIR（AOSP QEMU 源码根）; gfx = $GFX_DIR（gfxstream 源码根）
#   relpath : 相对该根的文件路径；填 * 表示在整棵树里按 token 搜
#   token   : 一个**应当长期稳定**的标识串（函数名/宏/标识符），用来判断"这段代码还在不在"
#   mark    : 可选，补丁插入的幂等标记；命中它 = 该补丁「已应用」
#
# 关键字失效（❌）= 该处代码被上游改名/搬走/删掉了 → 打开新源码重找等价点、改写锚点。
